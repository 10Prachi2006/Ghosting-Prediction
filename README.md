# 💀 Ghosting Predictor

> *"You already know the answer. The AI just confirmed it."*

An ML-powered relationship reality check that predicts whether someone will reply — and whether you're being ghosted — based on conversation signals.

**Live Demo:** [ghosting-predictor.hf.space](https://huggingface.co/spaces/YOUR_USERNAME/ghosting-predictor)

---

## 🔮 What it does

Input details about your last message and their behaviour. Get back:

- **Reply probability** — how likely they are to respond
- **Ghost probability** — how likely you're being ghosted
- **Conversation Diagnosis** — interest level, effort balance, ghost risk, read status
- **Signal Breakdown** — red flags and green flags
- **Final Verdict** — a straight-up conclusion
- **What-If Simulator** — see how changing one thing shifts your odds
- **Shareable result card** — screenshot it and post

Four personality modes: 🧠 Normal · 💀 Savage · 😭 Emotional · 🤡 Delusional

---

## 🧠 How it works

Two separate calibrated Random Forest models:

| Model | Target | Accuracy | F1 | ROC-AUC |
|-------|--------|----------|----|---------|
| Reply Model | Will they reply? | ~71% | ~0.60 | ~0.77 |
| Ghost Model | Are you being ghosted? | ~77% | ~0.86 | ~0.73 |

**Key design decisions:**
- Proper 3-way split (70% train / 15% calibration val / 15% test) — no data leakage
- `class_weight='balanced'` to handle class imbalance
- Sigmoid calibration for well-calibrated probabilities (Brier score ~0.18)
- Persona-driven synthetic data (`user_type` feature exposed to model)
- Mode-adjusted display probabilities (±7–18% deltas per personality mode)

## 📊 Dataset

Synthetic data generated by `gen_data5.py` — 10,000 rows with persona-driven generation:

| Feature | Description |
|---------|-------------|
| `response_time_gap` | Hours since message was sent |
| `reply_ratio` | Proportion of messages they've replied to |
| `message_tone` | dry / neutral / enthusiastic |
| `seen_ignored` | Message seen but no reply |
| `past_ghosting_history` | Have they ghosted before |
| `user_type` | interested / casual / dry_texter / ghoster |
| `conversation_length` | Total messages exchanged |
| `question_asked` | Whether you asked a question |

Targets: `reply` (binary) and `ghosted` (binary), generated independently with additive probability logic, capped at 0.92 to prevent stacking explosion.
